### 2.2 结构化数据（JSON-LD）

首页包含 **5 套 Schema.org**：
- Organization（企业信息 + sameAs + aggregateRating + certification）
- BreadcrumbList（面包屑）
- WebSite（含 SearchAction）
- ProfessionalService（服务目录 + GeoCoordinates + openingHours）
- WebPage（页面元信息）

**评价**：结构化数据非常完善，是国内少有的多类型覆盖。**建议**：ProfessionalService 的 `areaServed` 用 State 类型（仅陕西省），但 Organization 的 `areaServed` 是数组（18城市）—— 两者不冲突，但可统一为 City 数组更精确。

### 2.3 内链结构

- 首页内链：~178 个 `<a>` 标签
- 内链分布：contact.html 出现 13 次（合理，CTA 密集），其他核心页 1-3 次
- 外链：92 个，含 qcc.com/gsxt.gov.cn/tianyancha.com 等权威信源
- 外链安全属性：18 个含 `noopener`/`target="_blank"`

**评价**：内链丰富，权威外链多。**问题**：外链到第三方征信平台未加 `rel="nofollow"`——这些是高权重外链出流，每页 6 个 sameAs 外链会分散页面权重。建议 sameAs 链接加 `rel="noopener noreferrer nofollow"`。

### 2.4 图片 SEO

| 检查项 | 结果 | 评价 |
|--------|------|------|
| 首页 `<img>` 数量 | 1 个 | ⚠️ 过少，大量视觉内容可能是 CSS 背景图 |
| alt 属性 | 1 个 | ⚠️ 与 img 数量匹配，但 img 总量太少 |
| lazy loading | 0 个 | ❌ 无 `loading="lazy"` |
| OG 图片 | hero-bg-cbd.jpeg | 可访问，但大小未知 |

**关键问题**：首页视觉非常丰富，但仅 1 个 `<img>` 标签——说明大量图片是 CSS `background-image`。这导致：
1. **图片搜索收录几乎为 0**（百度图片/Google Images 无法索引 CSS 背景图）
2. **缺少 alt 文本**（背景图无法加 alt）
3. **可能影响 LCP**（背景图加载优先级低于 `<img>`）

> **没有安装任何流量分析工具 = 不知道流量从哪来、不知道哪些页面在掉流量、不知道用户行为路径。**

这是流量低迷的**最直接技术原因**。即便 SEO 做得再好，没有数据反馈就无法：
- 发现哪些关键词在带来流量
- 发现哪些页面跳出率过高
- 发现哪些页面被搜索引擎降权
- A/B 测试标题/描述的 CTR 效果
