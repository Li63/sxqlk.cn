# 流量监测接入指南（纯静态站点版）

> 配套工具：`_insert_tracking.py`（已放在站点根目录，一键批量插入全站 HTML）
> 纯静态站是最简单的情况：不需要后端，只要"注册 → 复制代码 → 填入脚本 → 全站插入 → 重新部署"五步。

---

| 平台 | 作用 | 优先级 | 注册地址 |
|------|------|--------|----------|
| 百度搜索资源平台 | 看收录量/展现/点击/关键词排名，提交 sitemap | **P0** | ziyuan.baidu.com |

| Google Analytics 4 | 看 Google 端流量行为 | P1 | analytics.google.com |

## 二、百度搜索资源平台（P0，先做这个）

### 步骤
1. 打开 **ziyuan.baidu.com**，用百度账号登录（没有就注册一个）。
2. 进入「用户中心 → 站点管理 → 添加网站」：
   - 输入 `www.sxqlk.cn`
   - 站点领域选「信息技术」或「企业服务」
3. **验证网站**——三选一，纯静态站推荐第 1 种：
   - ✅ **文件验证**：下载一个 `BaiduVerify_xxxx.txt` 文件，扔到网站根目录和 `index.html` 一起，重新部署，点「完成验证」。
   - HTML 标签验证：复制一串 `<meta name="baidu-site-verification" content="code-xxx">`，填到 `_insert_tracking.py` 的 `baidu_verify_content`，用脚本批量插入。
4. 验证通过后：
   - 「普通收录 → sitemap」提交 `https://www.sxqlk.cn/sitemap.xml`
   - 「普通收录 → API 推送」拿到 **token**（你的 `baidu-push.js` 可能已配，检查即可）

### 你能看到什么数据
- 索引量（真实收录了多少页）
- 流量与关键词（哪些词带来展现/点击、排名位置）
- 抓取异常（哪些页面 404/5xx）
- 抓取频次

## 三、百度统计（P0）

### 步骤
1. 打开 **tongji.baidu.com**，同一百度账号登录。
2. 「管理 → 新增网站」：网站域名填 `www.sxqlk.cn`，其他默认。
3. 创建后给你一段代码，长得像：
   ```html
   <script>
   var _hmt = _hmt || [];
   (function() {
     var hm = document.createElement("script");
     hm.src = "https://hm.baidu.com/hm.js?a1b2c3d4e5f6...";  ← 只需要这串 key
     ...
   })();
   </script>
   ```
4. 复制 `hm.js?` **后面那一串**（32 位），填到 `_insert_tracking.py` 的 `baidu_tongji_key`。
5. 执行批量插入（见第五节），重新部署。
6. 回到百度统计点「检查代码安装」，显示绿色即生效。

### 子域名分站说明
81 个子域名站（xian.sxqlk.cn 等）**不需要单独建站点**：在百度统计站点设置里，把「网站域名」改为 `sxqlk.cn`（不带 www），即可自动统计所有子域名流量。

## 四、Google Search Console + GA4（P1）

### GSC
1. 打开 **search.google.com/search-console**，用 Google 账号登录。
2. 「添加资源」→ 选**网址前缀** → 输入 `https://www.sxqlk.cn/`。
3. 验证方式选「HTML 标记」：复制 `content="..."` 里的值，填到 `_insert_tracking.py` 的 `gsc_verify_content`。
4. 批量插入 + 部署后点「验证」。
5. 提交 sitemap：`https://www.sxqlk.cn/sitemap.xml`。

### GA4
1. 打开 **analytics.google.com** → 「创建账号」→ 填 `sxqlk.cn`。
2. 创建数据流 → 「网站」→ 得到衡量 ID（`G-` 开头）。
3. 填到 `_insert_tracking.py` 的 `ga4_id`。

> ⚠️ 注意：GA/GSC 依赖 Google 服务，国内用户访问统计 JS 可能超时（不影响页面加载，因为加了 `async`）。如果你的客户全在国内，这两项可以放 P2 慢慢做，百度系优先。

## 五、一键批量插入（脚本用法）

代码都拿到后：

```bash
# 1. 编辑 _insert_tracking.py 顶部的 CONFIG，填入各 key

# 2. 预览（不写文件，看会改哪些页）
python _insert_tracking.py --dry

# 3. 确认后执行
python _insert_tracking.py --apply
```

- 脚本幂等：重复运行不会重复插入。
- 默认覆盖：根目录 17 个 HTML + `news/` + `cases/`。
- 如需覆盖 18 个城市子目录页和 subsites/，编辑脚本里的 `collect_files()` 加对应目录。

## 八、访客可见性与数据保密设置（重要）

### 8.1 先说结论：访客前台看不到任何东西

`_insert_tracking.py` 生成的是标准异步统计代码：

```html
<script>var _hmt=_hmt||[];(function(){...})();</script>
```

它的工作方式是**在后台静默建一张 1×1 的透明像素请求**，不会在页面上渲染：

- ✅ 前台**没有任何图标、文字、悬浮窗**
- ✅ 不影响页面布局（无占位、无 CSS 变化）
- ✅ 不弹窗、不打扰用户
- ✅ 不改变页面任何可见内容

> 对比：早期的 CNZZ、51.la 那种"今日访问量 XX"的可见计数器才会显示。
> 百度统计 / GA4 默认就是**纯后台无感**的，不需要额外隐藏。

### 8.2 必须在后台手动关闭的两个开关

虽然前台无感，但百度统计后台有两个选项，**默认建议检查并关闭**：

| 开关 | 位置 | 建议 | 原因 |
|------|------|------|------|
| **图标统计** | 百度统计 → 管理 → 网站设置 → 图标统计 | **确认关闭** | 开启后会在页面角落显示"百度统计"图标 |
| **数据共享** | 百度统计 → 管理 → 网站设置 → 数据共享 | **关闭** | 开启后你的数据可能被用于行业对外公开的排行/指数 |

### 8.3 数据只有你自己能看到

| 平台 | 访客能否看到数据 | 说明 |
|------|-----------------|------|
| 百度统计 | ❌ 不能 | 需百度账号登录，数据完全私密 |
| 百度资源平台 | ❌ 不能 | 同上，仅验证过的账号可见 |
| GSC / GA4 | ❌ 不能 | Google 账号登录可见 |
| 页面源码里的统计代码 | ⚠️ 能看到代码 | 但看不到任何数据 |

> **关于源码可见**：所有网站的统计代码在"查看源代码"里都能看到——
> 这是行业通行做法，腾讯、阿里官网也一样。竞品最多看到你"用了百度统计"，
> 拿不到你的任何流量数字。

### 8.4 账号权限：别给多余的人开权限

- 百度统计「管理 → 账号设置」里**不要添加子账号**（除非要给同事看）
- 百度资源平台同理，只保留你自己一个管理员

### 8.5 隐私合规建议（可选但推荐）

《个人信息保护法》要求使用 Cookie 类统计需告知。你的首页表单已有隐私同意选项，
建议再补一个**独立的隐私政策页**（如 `privacy.html`），写明：

> 本站使用百度统计等工具收集匿名访问数据（来源、页面、停留时长），
> 用于改善网站体验，不识别个人身份。
